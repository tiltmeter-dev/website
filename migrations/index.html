When a provider retires a model or removes a field, Tiltmeter can open a pull request that adapts the code still using it. These are the 84 pull requests it opened between 2026-10-26 and 2026-10-27 in other people's repositories, grouped by the change they fix. So far 18 have landed: 15 merged as written and 3 adopted by maintainers who landed the fix themselves. It is the view a hosted version would give a provider: which of its users' repositories got a fix, and how many took it.

Stars come from GitHub at the time of the snapshot, counted once per repository. 3 pull requests were closed because the maintainer landed the fix in a commit or pull request of their own, often with Tiltmeter's commit inside: it shows as Adopted, links to where the fix landed and counts as landed, not merged. 1 pull request was closed in favour of the maintainer's own pull request, still open: it shows as Picked up and counts as closed until that merges. 1 repository was deleted or made private after the pull request opened: it counts as opened and closed, without a name. Private repositories are counted but not named: their pull requests add to the counts above, while their names, links and stars are left out. There are none in this snapshot.
