When a provider retires a model or removes a field, Tiltmeter can open a pull request that adapts the code still using it. These are the 84 pull requests it opened between 2026-10-26 and 2026-10-27 in other people's repositories, grouped by the change they fix. It is the view a hosted version would give a provider: which of its users' repositories got a fix, and how many merged it.
